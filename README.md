# Website DIY-Shop Würzburg
![Startseite](https://github.com/purplepauli/Website_DIY-Shop/blob/main/public/images/DIYShop_Startseite.png?raw=true)

Eine Fullstack-Webanwendung für einen fiktiven DIY-Shop, entwickelt als studentisches Gruppenprojekt im Fach Webapplikationen an der Hochschule Fulda.

## 🛠️ Technologien & Architecture
* **Backend:** Node.js, Express.js
* **Frontend:** HTML5, CSS3, JavaScript (Views & Templates)
* **Konzept:** Server-Side Rendering / MVC-Muster

## 🎯 Features
* Produktübersicht und Detailseiten für Heimwerker-Bedarf
* Online-Shop mit Login-Funktion und Warenkorb
* Projektguides mit Verlinkungen zu passenden Produkten aus dem eigenen Online-Shop
* Informative Sicherheitsratgeber
* Backend-Routing für verschiedene Kategorien und Seiten
* Responsive Design für mobile Geräte und Desktops

## 👥 Team & Eigener Beitrag
Das Projekt wurde in einem 3-köpfigen Team umgesetzt. Jedes Teammitglied kümmerte sich dabei um ein zentrales Feature der Seite, aufgeteilt nach Onlineshop & Warenkorb, Login & Mitarbeiteroberfläche und Projektguides, Sicherheitsratgeber & Gestaltung der Startseite.

**Mein Schwerpunkt:**
Projektguides, Sicherheitsratgeber & Gestaltung der Startseite.

## 🚀 Projekt lokal starten
1. Projekt herunterladen: Code -> Download ZIP
2. Abhängigkeiten installieren: `npm install`
3. Anwendung starten: `npm start` oder `npm run dev`
4. Im Browser aufrufen: http://localhost:3000/
